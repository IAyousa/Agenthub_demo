## 2. Spring Boot 配置

### 2.1 主配置文件

默认使用 H2 文件模式数据库，零部署成本启动，并通过 `spring.config.import` 可选加载本地敏感配置。

```yaml
# backend-java/src/main/resources/application.yml

spring:
  config:
    import: optional:classpath:application-secret.yml   # 可选加载本地敏感配置
  application:
    name: agenthub
  h2:
    console:
      enabled: true
      path: /h2-console
      settings:
        trace: false
        web-allow-others: false
  datasource:
    url: jdbc:h2:file:./shared-data/agenthub;AUTO_SERVER=TRUE
    username: sa
    password:
    driver-class-name: org.h2.Driver
  sql:
    init:
      mode: always
      encoding: UTF-8
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    defer-datasource-initialization: true
    properties:
      hibernate:
        format_sql: true
        dialect: org.hibernate.dialect.H2Dialect
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB

server:
  port: 8080

agent:
  service:
    url: http://localhost:8000
    timeout: 120000

cors:
  allowed-origins: http://localhost:5173

artifact:
  storage:
    path: ./artifacts

# JWT 配置（敏感值见 application-secret.yml.example）
jwt:
  secret: ${JWT_SECRET:agent-hub-dev-jwt-secret-key-for-jjwt-256bit}
  expiration: ${JWT_EXPIRATION:86400000}
```

### 2.2 敏感配置分离

真实敏感值通过 `${VAR:default}` 占位符模式管理，日常开发使用默认值，生产环境注入环境变量：

| 配置项 | 环境变量 | 开发默认值 |
|--------|----------|-----------|
| `jwt.secret` | `JWT_SECRET` | `agent-hub-dev-jwt-secret-key-for-jjwt-256bit` |
| `jwt.expiration` | `JWT_EXPIRATION` | `86400000`（24 小时） |

本地开发可复制模板文件集中管理敏感配置：

```bash
cp application-secret.yml.example application-secret.yml  # 已被 .gitignore 保护
```

```yaml
# backend-java/src/main/resources/application-secret.yml.example
# 复制此文件为 application-secret.yml 并填入真实值

jwt:
  secret: agent-hub-dev-jwt-secret-key-for-jjwt-256bit  # 开发默认，生产更换
  expiration: 86400000
```

### 2.3 PostgreSQL Profile（可选）

通过 Spring Profile 实现 H2/PostgreSQL 双模式切换，无需修改 application.yml：

```yaml
# backend-java/src/main/resources/application-pg.yml
# 激活方式: mvn spring-boot:run -Dspring-boot.run.profiles=pg

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/agenthub?charSet=UTF-8
    username: ${PG_USERNAME:agenthub}
    password: ${PG_PASSWORD:agenthub123}
    driver-class-name: org.postgresql.Driver
  sql:
    init:
      data-locations: classpath:data-pg.sql
  jpa:
    properties:
      hibernate:
        dialect: org.hibernate.dialect.PostgreSQLDialect
```

种子数据使用 PostgreSQL 幂等语法（`INSERT ... ON CONFLICT DO NOTHING`），文件位于 `data-pg.sql`。

**迁移执行步骤**：

1. `docker-compose up -d` → 启动 PostgreSQL 容器
2. `mvn spring-boot:run -Dspring-boot.run.profiles=pg` → 使用 PG Profile 启动
3. 验证：控制台出现 PostgreSQL 建表 SQL 日志

**日常开发无需这些步骤**——默认 H2 零依赖直接启动。

## 6. 快速启动检查清单

以下为当前可执行的启动步骤。H2 为内嵌数据库，无需额外安装或启动。

| 步骤 | 命令 | 预期结果 |
|------|------|---------|
| 0. 复制配置模板 | `cp agent-service/.env.example agent-service/.env`（填入 API Key） | 本地 `.env` 就绪 |
| 1. 启动 Agent 服务 | `cd agent-service && uvicorn main:app --port 8000` | `localhost:8000/health` → `{"status":"ok"}` |
| 2. 启动 Java 后端 | `cd backend-java && mvn spring-boot:run` | 控制台输出 `Started AgenthubApplication`，端口 8080 |
| 3. 启动前端 | `cd frontend && npm install && npm run dev` | `localhost:5173` 看到 IM 聊天界面 |
| 4. 注册用户 | `POST localhost:8080/auth/register` | 返回 JWT Token |
| 5. 开始聊天 | 前端或 Swagger `localhost:8000/docs` | Agent 回复 |

> **注意**：
> - 步骤 0 只需首次执行。`.env` 和 `application-secret.yml` 均已 gitignored。
> - 默认使用 H2 文件数据库，数据持久化到 `./shared-data/agenthub`。
> - PostgreSQL 模式：`docker-compose up -d` → `mvn spring-boot:run -Dspring.profiles.active=pg`。
> - JWT 认证默认开启，未登录请求返回 401，需先 `/auth/register` 或 `/auth/login`。
