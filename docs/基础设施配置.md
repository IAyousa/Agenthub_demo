## 2. Spring Boot 配置

### 2.1.1 P1 阶段 H2 → PostgreSQL 迁移指南

迁移操作共需改动 **1 个 YAML 文件（5 行配置）+ 1 个 SQL 种子文件（2 条语句）**，所有 Java 代码和 Python 代码无需任何改动。

**PostgreSQL 配置（替换上述 H2 配置）**：

```yaml
# ===== PostgreSQL 配置（P1 阶段启用）=====
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/agenthub
    username: agenthub
    password: agenthub123
    driver-class-name: org.postgresql.Driver
  sql:
    init:
      mode: never   # 种子数据只在首次部署时手动执行
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
    properties:
      hibernate:
        format_sql: true
        dialect: org.hibernate.dialect.PostgreSQLDialect
```

**配置变更对照表**：

| 配置项 | H2（MVP） | PostgreSQL（P1） |
|--------|-----------|-----------------|
| `spring.h2.console.*` | `enabled: true` | **整块删除** |
| `datasource.url` | `jdbc:h2:mem:agenthub;DB_CLOSE_DELAY=-1` | `jdbc:postgresql://localhost:5432/agenthub` |
| `datasource.username` | `sa` | `agenthub` |
| `datasource.password` | （空） | `agenthub123` |
| `driver-class-name` | `org.h2.Driver` | `org.postgresql.Driver` |
| `hibernate.dialect` | `org.hibernate.dialect.H2Dialect` | `org.hibernate.dialect.PostgreSQLDialect` |
| `sql.init.mode` | `always` | `never`（种子数据首次部署后不再需要） |

**种子数据 SQL 适配**：

当前 `data.sql` 使用的 `MERGE INTO ... KEY (id)` 是 H2 特有语法，PostgreSQL 需改为标准 SQL：

```sql
-- 旧语法（H2，当前 data.sql 中使用）
MERGE INTO agents (id, name, type, ...) KEY (id) VALUES (...);

-- 新语法（PostgreSQL 兼容）
INSERT INTO agents (id, name, type, ...) VALUES (...)
ON CONFLICT (id) DO NOTHING;
```

**迁移执行步骤**：

1. 将 `docker-compose.yml` 放入项目根目录（配置见本文档第 1 节）
2. `docker-compose up -d postgres` → 验证：`docker ps` 看到 `agenthub-postgres` 容器
3. 修改 `application.yml`（按上表替换 5 个配置项）
4. 修改 `data.sql`（`MERGE INTO` → `INSERT ON CONFLICT`）
5. 重启 Spring Boot → 验证：控制台出现 PostgreSQL 建表 SQL 日志
6. 使用 DBeaver/pgAdmin 连接 `localhost:5432` 验证 `agenthub` 数据库中的 5 张表

**不需要改动的部分**：

- 4 个 JPA Entity 类（全部使用 JPA 标准注解，无数据库方言依赖）
- 4 个 JPA Repository 接口（只依赖 `JpaRepository` 标准接口）
- `AgentGatewayService`、`WebSocketController`、`pom.xml`
- Python Agent 服务（该服务不持有数据库，完全无影响）

> 📖 完整分析详见 `agent_collaboration/开发过程记录-数据库持久化机制分析.md`

## 6. 快速启动检查清单

以下为当前 MVP 阶段可执行的启动步骤。H2 为内嵌数据库，无需额外安装或启动。

| 步骤 | 命令 | 预期结果 |
|------|------|---------|
| 1. 启动 Java 后端 | `cd backend-java && mvn spring-boot:run` | 控制台输出 `Started AgenthubApplication`，端口 8080 |
| 2. 启动 Agent 服务 | `cd agent-service && uvicorn main:app --port 8000` | 访问 `localhost:8000/health` 返回 `{"status":"ok"}` |
| 3. 启动前端 | `cd frontend && npm install && npm run dev` | 访问 `localhost:5173` 看到 IM 聊天界面 |

> **注意**：
> - Java 后端和 Agent 服务目前均为骨架代码，启动后业务功能有限。
> - 步骤 1 需要本地安装 Maven（或使用 IDE 内置的 Maven 插件）。
> - 步骤 2 建议先创建虚拟环境 `python -m venv venv && venv\Scripts\activate`（Windows），再 `pip install -r requirements.txt`。
> - P1 阶段数据库切换到 PostgreSQL 时，增加步骤 0：`docker-compose up -d postgres`。
