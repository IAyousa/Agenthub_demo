## 2. Spring Boot 配置

### 2.1 主配置文件

当前 MVP 阶段使用 H2 内嵌数据库，零部署成本启动。实际配置如下：

```yaml
# backend-java/src/main/resources/application.yml

server:
  port: 8080

spring:
  application:
    name: agenthub
  h2:
    console:
      enabled: true                   # H2 Web 控制台（开发调试用）
      path: /h2-console
      settings:
        trace: false
        web-allow-others: false
  datasource:
    url: jdbc:h2:mem:agenthub;DB_CLOSE_DELAY=-1
    username: sa
    password:
    driver-class-name: org.h2.Driver
  jpa:
    hibernate:
      ddl-auto: update                # 开发环境自动建表
    show-sql: true                    # MVP 阶段打印 SQL，方便调试
    properties:
      hibernate:
        format_sql: true
        dialect: org.hibernate.dialect.H2Dialect
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 10MB

# Agent 服务地址
agent:
  service:
    url: http://localhost:8000
    timeout: 120000

# 产物存储路径（MVP 使用本地文件系统）
artifact:
  storage:
    path: ./artifacts
    url-prefix: /artifacts
```

> **P1 阶段切换到 PostgreSQL**：只需修改 `datasource` 和 `jpa.properties.hibernate.dialect` 配置项，
> 启动 `docker-compose up -d postgres` 即可，实体代码和 Repository 无需任何改动。

## 6. 快速启动检查清单

以下为当前 MVP 阶段可执行的启动步骤。H2 为内嵌数据库，无需额外安装或启动。

| 步骤 | 命令 | 预期结果 |
|------|------|---------|
| 1. 启动 Java 后端 | `cd backend-java && mvn spring-boot:run` | 控制台输出 `Started AgenthubApplication`，端口 8080 |
| 2. 启动 Agent 服务 | `cd agent-service && uvicorn main:app --port 8000` | 访问 `localhost:8000/health` 返回 `{"status":"ok"}` |
| 3. 启动前端 | `cd frontend && npm install && npm run dev` | 访问 `localhost:5173` 看到 IM 聊天界面 |

> **注意**：
> - Java 后端和 Agent 服务目前均为骨架代码，启动后业务功能有限。
> - 步骤 1 需要本地安装 Maven（或使用 IDE 内置的 Maven 插件）。
> - 步骤 2 建议先创建虚拟环境 `python -m venv venv && venv\Scripts\activate`（Windows），再 `pip install -r requirements.txt`。
> - P1 阶段数据库切换到 PostgreSQL 时，增加步骤 0：`docker-compose up -d postgres`。
