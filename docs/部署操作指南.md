# AgentHub — 部署操作指南

> **版本**: v1.0
> **最后更新**: 2026-06-10
> **适用环境**: Linux 云服务器 + Docker Compose
> **目标场景**: 对外演示 / 团队内部测试

---

## 一、架构概览

部署后 4 个容器协作运行：

```
 浏览器 (:80)
     │
  ┌──▼────────────┐
  │  nginx (:80)  │  前端静态文件 + API 反代
  └──┬────────────┘
     │
     ├──► backend (:8080)    Spring Boot Java 后端
     │      ├── H2 数据库 (/data/h2)
     │      ├── 产物存储  (/data/artifacts)
     │      └── 工作区    (/data/workspaces)
     │
     ├──► agent (:8000)      FastAPI Python Agent 服务
     │      ├── Claude Code CLI (npm global)
     │      └── 工作区共享卷 (/data/workspaces)
     │
     └──► postgres (:5432)   PostgreSQL (可选，pg profile)
```

## 二、环境准备

### 2.1 服务器要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| CPU | 2 核 | 4 核 |
| 内存 | 4 GB | 8 GB |
| 磁盘 | 20 GB | 50 GB+ |
| 操作系统 | Ubuntu 20.04+ / CentOS 8+ / Debian 11+ | Ubuntu 22.04 LTS |
| 网络 | 开放 80 端口（HTTP） | 开放 80 + 443（若配置 HTTPS） |

### 2.2 安装 Docker

```bash
# Ubuntu / Debian
curl -fsSL https://get.docker.com | bash
sudo usermod -aG docker $USER
# 退出重新登录使权限生效

# 验证安装
docker --version
docker compose version
```

### 2.3 开放防火墙端口

```bash
# Ubuntu (ufw)
sudo ufw allow 80/tcp
sudo ufw allow 22/tcp   # SSH — 务必保留！
sudo ufw enable

# 云服务器还需在控制台安全组中放行 80 端口
```

### 2.4 安装 Git（从仓库拉取代码）

```bash
sudo apt-get install -y git
git clone <你的仓库地址> /opt/agenthub
cd /opt/agenthub
```

## 三、配置

### 3.1 创建环境变量文件

```bash
cd /opt/agenthub
cp .env.docker .env
```

编辑 `.env` 填入真实值：

```ini
# 必需 — 填入你的 Anthropic API Key
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxx

# 可选 — 使用 Codex Agent 时需要
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx

# JWT 签名密钥 — 生产环境务必修改！
JWT_SECRET=使用随机字符串生成器生成至少 32 位字符

# 对外访问地址 — 改为服务器 IP 或域名
# 格式: http://你的服务器IP 或 http://你的域名
CORS_ORIGINS=http://123.456.789.0
```

### 3.2 验证配置

```bash
# 确保 .env 存在且包含必需变量
grep ANTHROPIC_API_KEY .env
grep JWT_SECRET .env
```

## 四、构建与启动

### 4.1 构建镜像

```bash
cd /opt/agenthub

# 构建全部 3 个服务镜像（首次约 5-10 分钟）
docker compose build

# 查看构建的镜像
docker images | grep agenthub
```

### 4.2 启动服务

```bash
# 后台启动所有服务
docker compose up -d

# 查看启动状态
docker compose ps

# 预期输出:
# NAME               STATUS
# agenthub-nginx     Up
# agenthub-backend   Up (healthy)
# agenthub-agent     Up
```

### 4.3 查看日志

```bash
# 实时查看所有服务日志
docker compose logs -f

# 只看某个服务
docker compose logs -f backend
docker compose logs -f agent
```

### 4.4 首次启动等待

backend 和 agent 镜像首次启动较慢：
- **backend**：Spring Boot 初始化 + H2 建表（约 20-40 秒）
- **agent**：FastAPI 启动（约 5 秒）

观察日志直到看到：
```
agenthub-backend  | Started AgenthubApplication in 30.123 seconds
agenthub-agent    | Uvicorn running on http://0.0.0.0:8000
```

## 六、运维操作

### 6.1 常用命令速查

| 操作 | 命令 |
|------|------|
| 启动 | `docker compose up -d` |
| 停止 | `docker compose down` |
| 重启 | `docker compose restart` |
| 查看状态 | `docker compose ps` |
| 查看日志 | `docker compose logs -f [服务名]` |
| 进入容器 | `docker exec -it agenthub-backend sh` |
| 重建并启动 | `docker compose up -d --build` |
| 清理所有数据 | `docker compose down -v` |

### 6.2 更新部署

```bash
cd /opt/agenthub
git pull origin dev
docker compose up -d --build
# --build 强制重建镜像以包含最新代码
```

### 6.3 备份数据

```bash
# 备份 Docker 数据卷
docker run --rm -v agenthub_h2:/data -v $(pwd):/backup alpine tar czf /backup/h2_backup.tar.gz -C /data .
docker run --rm -v agenthub_artifacts:/data -v $(pwd):/backup alpine tar czf /backup/artifacts_backup.tar.gz -C /data .

# 恢复
docker run --rm -v agenthub_h2:/data -v $(pwd):/backup alpine tar xzf /backup/h2_backup.tar.gz -C /data
```

### 6.4 日志持久化

```bash
# 日志默认输出到 docker journal，可配置持久化
# 在 docker-compose.yml 的每个 service 下添加:
#   logging:
#     driver: "json-file"
#     options:
#       max-size: "10m"
#       max-file: "3"
```

## 七、故障排查

### 7.1 前端页面无法访问

```bash
# 检查 nginx 是否运行
docker compose ps nginx
# 检查 80 端口
curl -I http://localhost
# 查看 nginx 日志
docker compose logs nginx
```

### 7.2 Agent 回复报错

```bash
# 检查 ANTHROPIC_API_KEY 是否配置
docker exec agenthub-agent env | grep ANTHROPIC
# 检查 Claude CLI 是否安装
docker exec agenthub-agent claude --version
# 查看 Agent 日志
docker compose logs agent
```

常见原因：
- `ANTHROPIC_API_KEY` 未设置或无效
- Claude Code CLI 镜像构建失败（需 Node.js ≥18）
- API 配额耗尽

### 7.3 产物卡片不出现

```bash
# 检查 agent → backend 连通性
docker exec agenthub-agent curl -s http://backend:8080/
# 检查工作区目录
docker exec agenthub-agent ls -la /data/workspaces/
```

### 7.4 WebSocket 连接失败

检查 nginx 配置中的 `/ws-chat/` 反代是否正确：
```nginx
proxy_http_version 1.1;
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
```

### 7.5 完全重置

```bash
cd /opt/agenthub
docker compose down -v    # 删除所有容器 + 数据卷
docker compose up -d      # 重新创建
```

## 八、生产加固建议（可选）

以下为演示环境可跳过的生产级加固措施：

| 措施 | 说明 |
|------|------|
| HTTPS | 使用 Let's Encrypt + Certbot 配置 SSL 证书 |
| PostgreSQL | 启用 PG Profile 替代 H2 文件数据库 |
| Redis | 启动 Redis 容器支持 Token 黑名单登出 |
| 非 root 运行 | 为每个容器添加 `user: "1000:1000"` |
| 资源限制 | `docker-compose.yml` 添加 `deploy.resources.limits` |
| 监控 | 接入 Prometheus + Grafana 或简单的 `docker stats` |
| 日志聚合 | 使用 `docker compose logs` + 定时归档 |
